# Databricks-Project

Welcome to the **Databricks Project Repository**! The goal of this project is to build a data pipeline from API-ingestion via warehousing and model training to a dashboard solution. Designed as a portfolio project, it highlights industry best practices in data engineering and econometrics.

-
## Project Requirements

-
### Data Engineering
**Objective:**
Develop a modern analytical pipeline to funnel data and predictions into a dashboard.

**Specifications:**
- Data Sources: yfinance API
- Data Cleansing: Light transformations and data logging
- Integration: Integrate stock data and stock predictions into a final dataset
- Scope: Last two years, rolling
- Documentation: Provide a clear line of documentation on the data warehouse and the predictive model

-
### Data Analytics
Provide insights into:
- Stock prediction
- Confidence interval
- Movement-related factors
